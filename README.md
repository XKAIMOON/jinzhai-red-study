# 经纬金寨红 · 解码 28 年

> 鄂豫皖大别山红色旅游创意策划大赛 · 红色研学课程设计赛道
> 配套网站 ——《多视角解密红色文化：大别山红色精神的学习与传承之金寨研学》

金寨不是一个「有很多红色景点」的地方。它是北纬 31° 上的一条山脊，把鄂豫皖三省缝在一起；
是 116 座千米山峰围出的屏障，让政权守得住；是史河出山的那条河谷，让政权活得下去。

**用等高线读历史，用行政区划看缝隙，用河谷走向追英雄。**

## 在线访问

启用 GitHub Pages 后：`https://<用户名>.github.io/<仓库名>/`

单页站点，无需构建，直接打开即用。

页头在滚动时是吸顶的，点右上角「收起页头」可把它压成一条窄栏（只留图层开关与七段导航），
点「展开页头」复原；状态记在浏览器本地，刷新后保持。

## 数据来源

| 内容 | 来源 |
|---|---|
| 高程与等高线 | NASA SRTM（AWS Terrain Tiles, zoom 11） |
| 行政区划 | Natural Earth 1:10m 省界 + OpenStreetMap 金寨县界 |
| 水系与库区 | OpenStreetMap（ODbL）；梅山 / 响洪甸库区由 DEM 平坦面反演 |
| 路线与里程 | OSRM 公路路径规划（79.6 km / 约 64 分钟） |
| 沿线条幅影像 | Wikimedia Commons，CC BY-SA 3.0 / 4.0（作者见页脚署名） |

剧本杀模块中的距离、最高点与累计爬升，均由 SRTM 高程沿真实道路或直线每 60 米取样统计，可复算。
